# Drive 影片下載器

## 安裝

1. 在 Chrome 開啟 `chrome://extensions/`。
2. 開啟「開發人員模式」。
3. 點選「載入未封裝項目」，選取包含 `manifest.json` 的這個資料夾。

## 使用

1. 在 Google Drive 開啟影片預覽並播放。
2. 點開擴充功能。偵測到的媒體會顯示在「影片」與「音軌」清單。
3. 點選所需項目的「下載」。擴充功能會移除連結的 `range` 和 `ump` 參數，在背景開啟播放器分頁，並從該頁面發出下載請求。
4. Chrome 確認下載開始後，擴充功能會切換到播放器分頁並播放。下載期間每隔約五秒隨機跳到 1% 至 99% 的位置，直到下載停止。下載進度可在 Chrome 下載記錄查看。

如果影片已經在安裝前開啟，請重新整理 Google Drive 頁面後再播放。播放連結過期時，也可以重新整理後重試。部分影片串流需要另外下載音軌。

播放連結只儲存在目前 Chrome 工作階段。重新整理、切換頁面或關閉分頁時，擴充功能會清除該分頁的清單。
